# Issue Tracker

A dependency-free full-stack JavaScript implementation of the freeCodeCamp Issue Tracker challenge.

## Run

```bash
npm start
```

Open `http://localhost:3000/`.

## Test

```bash
npm run test
```

The app implements:

- `POST /api/issues/{project}`
- `GET /api/issues/{project}`
- `PUT /api/issues/{project}`
- `DELETE /api/issues/{project}`

The functional tests live in `tests/2_functional-tests.js`.
